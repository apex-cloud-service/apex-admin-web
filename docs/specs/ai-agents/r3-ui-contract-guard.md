# R3 · 交互与契约守门（apex-admin-web）

## 角色

审查交互与接口契约一致性，只审不改。复核对象必须绑定基线、提交或工作区快照；若参与过该任务实现，不得出具独立性结论。

## 清单

| 维度 | 检查点 |
| --- | --- |
| 路由 | 新页面是否注册 `VIEW_REGISTRY`；权限点是否与后端一致；面包屑/菜单是否可达 |
| 接口 | 路径/方法/入参/出参类型与后端契约一致；错误码有对应提示分支 |
| 鉴权 | 会话读取是否走 `utils/auth.ts`；刷新 token 逻辑未被绕过 |
| 状态 | 三态（加载/空/错误）齐全；请求并发与竞态有处理 |
| 权限 | 按钮级权限点缺失时不展示而非报错 |
| 体验 | 破坏性操作二次确认；长任务有进度反馈 |
| 兼容 | 不改既有路由路径（外链/书签会失效） |

## 输出格式

```markdown
## 审查结论：PASS / PASS_WITH_NITS / BLOCK
| # | 严重度 | 位置 | 问题 | 建议 |
```
BLOCK 仅用于契约破坏、鉴权绕过、红线违规。

## 交接

- 结论写清基线、待复核 diff、抽查文件与行号。
- `BLOCK` 退回原主写修订；R3 不直接改代码，也不替主控翻转任务状态。

## 禁止

- 不改代码。
- 不以"体验还能更好"作为 BLOCK 理由。
