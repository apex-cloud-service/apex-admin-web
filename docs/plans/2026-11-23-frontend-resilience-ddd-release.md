# FE-030 分波次实施计划

| 波次 | 范围与交付 | 验证 | 回滚 |
| --- | --- | --- | --- |
| A 基线 | 只读盘点页面域、API、状态、共享组件、依赖和发布配置；采集构建产物与性能数据 | `vue-tsc --noEmit`、`npm run test:report`、`npm run build`、`npm run test:e2e` 与红线检查，记录基线环境 | 仅撤销本波新增审计文档，不改业务代码 |
| B 架构与性能 | 依据证据选取最小模块，评估懒加载、重复依赖、重渲染、大列表及状态边界 | 变更前后同环境对比，补组件/路由回归；不达既定且经确认的目标则不合入 | 按组件/路由批次 revert |
| C 请求韧性 | 核查取消、超时、重复请求、缓存隔离/失效和安全重试；写操作保持不重试 | 用例覆盖过期响应、并发、权限变化、网络异常及幂等边界 | 回退对应 API 封装或配置，不触碰 FE-029 未提交联调改动 |
| D 发布与观测 | 核实静态资源版本、客户端缓存、错误追踪及托管层切流/回滚协作 | 有可用部署环境时演练旧/新资源兼容与回滚；否则标记未验证 | 恢复前版静态资产和缓存策略 |
| E 回归与复核 | 更新 docs/scripts/config/tests，重跑完整前端验证并生成报告，整理未验证项 | 类型检查、单测、构建、E2E、严格治理检查、独立 R5 | 每波单独 revert，报告保留 SHA 与真实执行记录 |

Wave A 的静态范围审计和 2026-11-24 带日志隔离复验均获独立 R5 `APPROVE_WITH_NITS`，复验含类型检查及构建、543 项单测、13 项生产预览 mock E2E，见[隔离复测记录](../records/2026-11-23-fe030-wave-a-test-report.md)。2026-11-23 登录页 Lighthouse 仅为静态基线，不替代 Wave B 的业务页面对比或容量基线。下一步以认证后业务页真实资源加载记录选择最小优化项，并在代码变更前登记独立租约。FE-030 未修改业务代码，未覆盖 FE-029 的共享产物或联调遗留。

2026-11-24：Wave B 已复现[认证后资源基线](../records/2026-11-23-fe030-wave-a-test-report.md#2026-11-24-wave-b-资源基线)。工作台独自加载图表包，两页均加载全局图标包。先验证将全量图标从应用入口移至认证布局是否保留动态名称解析及回退，再登记实施租约，用同一夹具比较登录页和认证后页面；没有对照证据前不宣称包体或性能收益。

Wave B1 先对不涉及路由或图标注册的 Element Plus 分包做了[隔离实验](../records/2026-11-23-fe030-wave-a-test-report.md#wave-b1-分包对照)，未达双页门槛，未采纳。图标负载仍需用独立登录页和授权布局对照，不与该候选叠加。

Wave B2 [隔离对照](../records/2026-11-23-fe030-wave-a-test-report.md#wave-b2-匿名入口图标对照)登录页解码 JS 减少 12.5%，认证页各增加 9 个 JS 资源条目；候选 543 单测与 14 项 E2E 通过。独立复核仅接收实验证据，生产采纳仍需冷缓存高延迟 A/B 和登录到工作台可交互 p95 对照。原仓应用未改；Wave C 的请求韧性与 FE-029 联调遗留继续分开管理。
