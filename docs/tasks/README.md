# 任务管理（docs/tasks）

本目录是任务治理的唯一入口。

- [任务大盘](./project-tasks.md) — 全量任务、优先级、状态、负责人、验收标准与风险登记

规则要点：
1. 仅主控智能体可写 `project-tasks.md`，其余智能体只读。
2. 一个会话只做一件任务；新需求先入表再动手。
3. 任务关闭需在 `docs/records/` 留变更记录。
4. 活跃卡必须有唯一主写、复核人、执行基线、写入范围和依赖/互斥关系；缺项不得进入「执行中」。
5. 并行任务使用独立 worktree/含任务 ID 的短分支，同一文件同一时段只允许一个主写。

## 标准交接包

执行智能体完成后回传以下内容，由主控更新任务状态：

```markdown
- 任务号 / 建议状态：
- 执行基线：分支或 worktree / 起始提交 / 最终提交或 diff
- 写入范围核对：范围内文件 / 范围外文件（应为无）
- 改动清单：新增 / 修改 / 删除
- 验证证据：命令 / 退出码或摘要 / 不可复跑项及交叉证据
- 风险与回滚：未验证边界 / 回滚提交或文件
- 下一步建议：待办 / 阻塞 / 范围外发现
```

主控只采纳完整交接包；R5 独立复核通过后才可置「已完成」。
