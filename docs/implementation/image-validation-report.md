## 六、图片使用建议

### 如果未来需要添加图片

#### 1. 目录结构建议

```
docs/
├── assets/
│   └── images/
│       ├── guides/
│       ├── features/
│       └── implementation/
├── guides/
├── features/
└── ...
```

#### 2. 命名规范

- 使用小写字母和连字符
- 包含语义化描述
- 示例：`deployment-architecture.png`, `file-upload-flow.svg`

#### 3. 引用方式

**Markdown 语法（推荐）：**
```markdown
![部署架构图](../assets/images/guides/deployment-architecture.png)
```

**HTML 标签（备选）：**
```html
<img src="../assets/images/guides/deployment-architecture.png" alt="部署架构图" width="600">
```

#### 4. 图片格式建议

| 格式 | 用途 | 优点 |
|------|------|------|
| PNG | 截图、UI界面 | 无损压缩，支持透明 |
| SVG | 架构图、流程图 | 矢量图，可缩放 |
| JPG | 照片 | 文件小 |
| GIF | 动画演示 | 支持动画 |

#### 5. 图片优化

- 控制文件大小（建议 < 500KB）
- 使用合适的分辨率
- 压缩图片以减小仓库体积

```bash

# 检查文档中的图片引用

echo "检查 Markdown 图片语法..."
grep -rn "!\[.*\](" docs/ --include="*.md" | wc -l

echo "检查图片文件..."

echo "检查外部图片 URL..."
```
